## Отключение OpenDesign Cloud в PDLC

Существующий `isPdlcMode()` отключает карточку регистрации в боковой панели,
`AmrLoginPill`, предложение Cloud в настройках и облачный агент `amr` в общих
списках выбора. Обёртки не монтируют Cloud-компоненты и их эффекты. Нового флага,
хранилища credentials или логина нет. Standalone-режим сохраняет Cloud-вход.
Серверная блокировка Cloud API уже существовала и не ослаблялась.

Приёмка текущей поставки: 26 scoped tests, root guard, общий workspace typecheck
и image build прошли. Все 17 выданных JS/CSS assets совпали с установленным
образом, весь квалифицированный daemon payload остался прежним. Auth, Tracker
и AI Hub сравнивались под общим lock до/после именно нашего cutover; их IDs,
образы, конфигурация и mounts совпали. Первую попытку остановил чужой активный
maintenance lock до замены контейнера; повтор выполнен после его освобождения.

В IAB проверены отсутствие Cloud-входа на главной и в настройках, отсутствие
Cloud в переключателе, прежний аккаунт PDLC3 Operator и тёмная тема. Серая тема
имеет отдельную проблему контраста родных надписей; она в этой поставке не
исправлялась. Возвращена ранее запрошенная Dark.

Модельный источник ещё не настроен: CLI не обнаружены, реальных модельных
вызовов не было. При полном запуске корня сохраняется штатный first-run мастер
локального CLI/API; тестовое завершение onboarding не записывалось. Главная
открыта через родную навигацию из Community, которую upstream разрешает как
прямую ссылку без перехвата onboarding. Этот предел настройки генерации не
означает отдельный вход в приложение.

## Проекты Task Tracker

Список читает только владелец `GET /api/v1/projects` от текущего браузерного
пользователя через same-origin `GET /api/pdlc/projects`. Private transport
`OD_PDLC_TRACKER_URL` добавлен только в декларацию OpenDesign, проверенную pinned
owner под общим maintenance lock. API не принимает destination от браузера,
не использует сервисный токен, запрещает redirects и ограничивает запрос 5 секундами.
Anonymous и PAT не могут использовать browser proxy. Права остаются у Tracker.

Вкладка сохраняет выбранный ID отдельно для текущего subject. Это контекст
выбора, без переписывания файлов студии, создания проектов Tracker или новых ACL.
Проекты студии не подставляются вместо каталога Tracker. В данном локальном
окружении текущему оператору доступно проектов: **0**; это совпало
с прямым ответом владельца. Положительный выбор другого проекта проверен scoped
UI/HTTP tests; живой каталог не заполнялся тестовыми записями. Legacy v1 не
объявляется новым ProjectAccessV2 и не обновляется ради этой интеграции.
